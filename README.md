# homebrew-fixen

Homebrew tap for [fixen](https://cmore.dev/fixen/), the menu bar app that fixes your writing in any app.

```sh
brew install --cask heoooooon/fixen/fixen
```

The cask installs the signed, notarized app from the
[`app-v*` releases](https://github.com/Heoooooon/fixen/releases) of Heoooooon/fixen.
The app updates itself (`auto_updates true`); `brew upgrade --cask fixen` also works.

The command-line tool is published on npm: `npm i -g fixen-cli`.
